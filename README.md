# PN-3DGS
Pose-Nested 3D Gaussian Splatting (PN-3DGS) formulates the coupled interplay between Gaussian reconstruction and pose estimation as a bilevel optimization problem. By employing a value-function penalty method, PN-3DGS avoids expensive Hessian computations and enables more robust SfM-free 3D Gaussian reconstruction.
